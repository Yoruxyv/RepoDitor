# RepoDitor v0.1.1

Released August 11, 2026. This Electron release expanded what players could
safely edit and added more control over the desktop experience.

## What's new

- A dedicated Cosmetics workspace shows ownership and preset counts and adds
  **Unlock All Cosmetics**, guarded **Lock All Cosmetics**, and **Clear All
  Presets**. Unknown IDs are preserved. Equipped or preset-referenced entries
  can block bulk locking.
- **Refill to Full** becomes available for eligible item instances. It changes
  the exact stored-charge entry when the confirmed save representation returns
  the item to its default full state.
- The editor actively guards against editing while R.E.P.O. runs. Run saves
  and MetaSave retain separate pending changes, fingerprints, and backups.
- Dark, Light, and System themes and five interface languages are available.
  Steam avatars fail gracefully, and the save-safety dialog is better scoped
  and centered.
- The assisted Windows NSIS installer adds consistent branding, shortcuts,
  and registration. Release tooling synchronizes version metadata and checks
  the packaged application and installer.
