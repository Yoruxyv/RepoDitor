# RepoDitor v0.2.1

Released August 21, 2026. This is a focused save-safety hotfix for the
Electron edition.

## Fixed

- Health, Upgrade, and Run edits now reject values outside the signed 32-bit
  range used by their save containers. In the published game test, the upper
  bound of `2,147,483,647` loaded successfully. The next integer could leave a
  save unusable.
- The editor rejects out-of-range pending edits, and both Electron and Python
  enforce the restriction before writing. Stale-source detection, exact-byte
  backups, staged verification, and atomic replacement continue to apply.
