# RepoDitor v0.2.0

Released August 21, 2026. This Electron release focused on full editor
preparation, installed-game artwork, and safer editing decisions.

## What's new

- The packaged Python backend moves to PyInstaller's directory layout, reducing
  startup work for short-lived backend commands. An explicit reopen can reuse a
  prepared view when a fresh read confirms the same save fingerprint.
- Run preparation reports progress from work it can measure. Installed upgrade
  textures are reused across restarts while their source identities still match.
- Items gain search, filters, sorting, and optional local icons. Recharge now
  requires authoritative installed-game metadata in addition to the exact
  instance's stored charge. Verified capability evidence can be reused within a
  session while the relevant source still matches.
- Cosmetics gains names, categories, rarity, local icons, search, filters,
  sorting, and eligible single-entry unlocks. Existing bulk protections and
  unknown-ID preservation continue to apply.
- The save pipeline rechecks whether R.E.P.O. is closed immediately before
  persistence and rejects editable fields with unsupported stored scalar
  representations. Pending review and navigation feedback are clearer.
