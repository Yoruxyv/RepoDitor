# RepoDitor v0.3.1

- **Upgrade artwork stays visible after saving.** RepoDitor keeps prepared
  Upgrade thumbnails when the installed artwork source still matches. Known
  truck upgrade pickups also use the matching game artwork where available.
- **Pending review is easier to use.** Long lists scroll within a compact
  panel. **Hide review** and Escape close the panel without discarding drafts.
  Review collapses when saving starts, and save progress stays visible.

## Windows x64

Download `RepoDitor-Setup-0.3.1-x64.exe` and its `.sha256` file from the same
GitHub release. Verify the SHA-256 before running the unsigned installer. Close
R.E.P.O. before editing saves.
