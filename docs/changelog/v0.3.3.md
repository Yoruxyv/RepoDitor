# RepoDitor v0.3.3

- Restores Desktop editing on R.E.P.O. Steam build `26893562` and retains
  support for verified v0.5.2 and v0.5.3 installations.
- Keeps supported edits available after compatible game updates. RepoDitor
  checks the installed save settings and operation requirements locally.
  An unfamiliar Steam BuildID alone no longer requires a new release or user
  acknowledgment. Changes to the save contract can still restrict affected edits.
- Enables Normal and Shop Resume when the saved selector, scene settings, and
  Level definitions pass validation. The dropdown opens on its first enabled click.
- Preserves Truck Item artwork during editor refresh. Existing Recharge identities
  and Cosmetics ownership slots remain editable after compatible catalog additions.
- Retains automatic encrypted backups, closed-game checks, and save recovery.

See the [Desktop compatibility policy](../maintenance/game-update-capabilities.md#tauri-editing-across-steam-patches)
for the checks and remaining limits.

## Windows x64

Download `RepoDitor-Setup-0.3.3-x64.exe` and its `.sha256` file from the same
GitHub release. Verify the SHA-256 before running the unsigned installer.
