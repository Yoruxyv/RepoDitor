# RepoDitor v0.3.2

- Restores Desktop editing for R.E.P.O. v0.5.3, Steam build `26813769`, across
  Health, Upgrades, Run and Resume, Item Recharge, and Cosmetics. The approved
  v0.5.2 sources also remain supported.
- RepoDitor verifies the required game files before allowing each editing
  domain. Editing on later Steam builds depends on matching the approved
  files. Close R.E.P.O. before saving changes.

## Windows x64

Download `RepoDitor-Setup-0.3.2-x64.exe` and its `.sha256` file from the same
GitHub release. Verify the SHA-256 before running the unsigned installer.
