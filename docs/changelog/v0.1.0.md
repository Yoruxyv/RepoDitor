# RepoDitor v0.1.0

Released August 9, 2026. The first public Windows x64 release shipped an
Electron editor with a bundled Python backend for local encrypted R.E.P.O.
Run saves.

## What's new

- Discover recent saves in the default Windows save directory and inspect the
  Run overview, Players, Upgrades, Run, installed Maps, and Advanced Items.
- Stage current Health, discovered player upgrades, and supported Run values.
  Review or revert edits before saving.
- Detect external save changes, create exact-byte backups, and validate staged
  output before atomically replacing the selected save.
- Show optional Steam avatars. Advanced item and battery details are read-only.

## Windows download

The unsigned installer includes Python, registers the app with Windows, and
creates a Start menu shortcut. Updates are manual. Uninstallation keeps game
saves and RepoDitor-created save backups. [Original release and downloads](https://github.com/Yoruxyv/RepoDitor/releases/tag/v0.1.0).
